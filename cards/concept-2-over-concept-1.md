# concept-2-over-concept-1

The post is illustrated with meaning-first diagrams turned into soft hand-drawn illustrations (concept 2), not character-driven comic panels (concept 1).

## The choice

Design each image around what changes in that phase (a diagram with one repository box whose contents evolve), get the meaning right as SVG, then generate a warm hand-drawn illustration from it.

## Alternatives considered

- **Concept 1** — everything before concept 2, kept for reference:
  - the author's hand sketches (`ai-phases.pdf`, local only)
  - comic panels drawn in code (`images/concept-1/code-drawn/`)
  - bold comic panels from ElevenLabs with halftone, yellow caption boxes and speech bubbles (`images/concept-1/comic/`; the post as it was is at git tags `concept-1` / `style-1`)
  - a softer redraw of the comic (`images/concept-1/style-2-phase-5.png`)
- Clean, flat SVG diagrams only (now the concept-2 diagrams) — clear but "machine, no feelings".

## Why this won

The comic panels showed who points at what, but not what each phase changes; a softer redraw was "still very similar". Drawing the meaning first fixed that, and the illustration pass adds the human, fun feel the author wanted without losing it.

## When to revisit

If the post becomes a comic strip or social-media series where punchy character art matters more than explaining the model.
